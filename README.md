# ¡Hola! Soy vanlishedz 👋

Me gusta crear mods para Minecraft Java que hagan más cómodas las pequeñas
cosas del juego. Voy aprendiendo y mejorando cada proyecto con las pruebas y
comentarios de quienes los usan.

## En lo que estoy trabajando

- **Inventario Ordenado** — atajos para ordenar tu inventario y algunos contenedores.
- **Emojis** — un selector de emojis integrado al chat.

Los dos proyectos son mods de cliente para Fabric. Cuando publique sus páginas
oficiales, agregaré aquí los enlaces de descarga.

## Sobre este perfil

Me gusta convertir ideas sencillas en mejoras útiles para Minecraft. Si pruebas
alguno de mis mods, tus comentarios y sugerencias son bienvenidos.
